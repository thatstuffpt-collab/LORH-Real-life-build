# LORH Real-Life Build

A gamified real-life player progression app for hoopers. Track workouts, build physical ratings, earn XP, unlock badges, and level up your game.

## V1 focus
- Strength training workout planning and logging
- XP, levels, streaks, and badges
- Overall and physical ratings tied to measurable progress
- PR tracking and workout history
- Local-first storage so the prototype works without a backend
- Mobile-friendly PWA foundation

Future phases will add speed/agility testing, vertical jump, basketball workouts, skill ratings, client accounts, cloud sync, and coach dashboards.
